Ring 0 eBPF Telemetry Engine

GhostRing is a modern, high-performance security observability subsystem written in pure Rust with Aya. Engineered with a strict 3-crate workspace architecture to deliver non-blocking, zero-trust system event auditing with kernel verifier safety.

GhostRing Technical Documentation & Architecture Reference #

This directory serves as the technical documentation suite and architecture reference for the GhostRing repository. It provides comprehensive specifications across kernel-space eBPF instrumentation, data transport mechanisms, user-space daemon operations, security and licensing compliance, and development workflows.

Documentation Index #

1. Foundational Architecture & Environment #

  • Architecture Overview — Comprehensive overview of the 3-crate workspace architecture, crate boundaries, and end-to-end telemetry pipeline.
  • Development Environment & Isolated Build System — System requirements (Linux 5.8+, BTF), in-repository isolated toolchain (.build-env/), automated bootstrap script (scripts/setup-env.sh), and verification.
  • eBPF Fundamentals — Core eBPF principles, execution model, probe types, memory safety, and kernel verifier requirements.
  • Kernel Instrumentation — Ring 0 execution path interception, tracepoints, kprobes, context extraction, and kernel safety guarantees.

2. Kernel Space & eBPF Engineering #

  • eBPF Internals & Bytecode — eBPF instruction set architecture (ISA), register conventions, verifier static analysis, ELF layout, and JIT compilation.
  • Aya Framework — Deep dive into the pure-Rust Aya ecosystem (aya, aya-ebpf, aya-poll), ELF loading, map abstractions, and helper bindings.
  • BTF & CO-RE Deep Dive — BPF Type Format (BTF) structure, Compile Once, Run Everywhere (CO-RE) field relocations, and kernel portability.
  • ghostring-common Struct Design — C-compatible #[repr(C)] memory layouts, alignment constraints, scalar type mappings, and cross-boundary ABI stability.

3. Telemetry & User Space Pipeline #

  • Event Transport — Telemetry transmission mechanics from Ring 0 to user space via PerfEventArray ring buffers.
  • Perf Buffer Internals — Low-level ring buffer memory layout, mmap headers, head/tail pointer synchronization, per-CPU ring handling, and backpressure management.
  • ghostring User Daemon — Asynchronous Tokio daemon architecture, per-CPU buffer polling loop, CLI options, event filtering, and structured logging.

4. Security, Compliance & Governance #

  • Security Requirements — Ring 0 zero-trust observability advantages, tamper resistance, and kernel licensing requirements.
  • Security Model Deep Dive — Threat model, evasion countermeasures, kernel rootkit resistance, and defense-in-depth principles.
  • License Compliance Deep Dive — GNU General Public License v3.0 (GPLv3) compliance analysis, Linux kernel verifier license checking, and BPF helper access.

5. Quality Assurance, Operations & Roadmap #

  • Build System & Workspace — Root Cargo workspace configuration, compilation targets (bpfel-unknown-none), bpf-linker integration, and CI/CD pipelines.
  • Testing Strategy — Four-layer testing pyramid (unit, struct layout, integration, and E2E testing), benchmark suites, and release quality gates.
  • Troubleshooting Guide — Diagnostic workflows and solutions for 19 common build, verifier, permission, and runtime errors.
  • Roadmap Features Deep Dive — Architectural blueprints for advanced path extraction (bpf_probe_read_user_str), socket observability (tcp_connect), and File Integrity Monitoring (sys_enter_openat).
